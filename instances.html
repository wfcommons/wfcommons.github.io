WfInstances

{{ num_traces }} open workflow execution instances

Workflow instances are widely used to profile and characterize workflow executions, and to build distributions of workflow execution behaviors, which are used to evaluate methods and techniques in simulation or in real conditions.

WfInstances collects and curates open access production workflow executions from various scientific applications, shared in the common WfFormat instance format. The WfCommons Python package provides tools for analyzing instances, which can be used to develop workflow recipes for WfGen.

Repositories

Open access instance repositories

Instances are organized by workflow system. Each sub-folder is a workflow application containing executions on different computing platforms, with a README.md that describes the workflow structure and points to relevant material.
